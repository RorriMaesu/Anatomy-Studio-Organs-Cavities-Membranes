# Tissue Studio — first release

- Six official sections, 24 short lessons, 100 term cards and 140 reviewed questions.
- Animated SVG teaching activities: tissue families, membrane/origin maps, epithelial classification, junctions, transitional stretch, secretion, fiber direction/recoil, cartilage comparison, muscle comparison, neuron signal steps and tissue repair.
- All 22 textbook figures extracted from the supplied PDF, with original lettering retained. Five image-only panels support microscope identification and evidence questions. Original figure-specific micrograph credits are preserved.
- Ten-question section practice; missed/assisted review; a 40-question chapter exam with quotas 6/10/10/5/4/5. Exam feedback is deferred; hints count as assistance in practice. Sessions resume after reload.
- Course library, chapter selectors, custom concept exams, progress aggregation, backup/restore and reset include Chapter 4. Restoring a backup invalidates stale tabs.
- Desktop study fits the 1280 × 720 viewport; long recall lists are paginated. Mobile testing at 390 × 844 showed no page-width overflow. Effects controls and system reduced-motion preferences are respected.

## Scope and limits
These are reviewed textbook examples, not an unseen-specimen assessment. Five micrograph panels do not represent comprehensive histology-slide diversity. The diagrams simplify anatomy and timing. Figures are study references rather than relabeled versions of every original panel; Figure 4.7 uses its micrograph panel. Tables 4.1 and 4.2 are covered in the lessons and available through the linked official sections. AI feedback is separate from reviewed scores. This release updates GitHub Pages; it does not rebuild an installed desktop bundle.
